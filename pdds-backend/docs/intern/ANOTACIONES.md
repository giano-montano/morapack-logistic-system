
Summary for Algorithms:

    Use Array
    when you have a fixed number of elements, need maximum performance for indexed access, and memory efficiency is a primary concern.
    Use ArrayList
    when you need a dynamic, ordered list, frequent indexed access, and are willing to accept potential performance implications for insertions/deletions in the middle.
    Use HashSet
    when you need to store unique elements, and fast average-case performance for checking existence, adding, and removing elements is crucial, regardless of element order.
